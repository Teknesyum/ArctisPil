## Uygulanmayan Kurallar

- **Gerçek pencere %125 ve %150'de.** Ekran ölçeğini değiştirmek sistem ayarıdır; değiştirilmedi. Bu iki ölçek, aynı `OnPaint` yolunu ölçek parametresiyle çizen başsız render ile alındı; gerçek pencere %100'de.
- **Tepsi rakamları Atkinson değil Bahnschrift.** Sahibin açık tercihi (simgeyi dolduran kalın rakam).
- **Yazı tipi Segoe UI (v0.4.3).** Sahibin açık isteği: panel ve menü Atkinson Hyperlegible Next / Cascadia Mono yerine sistemin Segoe UI ve Segoe UI Semibold'u; panel metni ClearType ile çizilir. Gömülü yazı tipleri `trash/fonts`'a taşındı.
- **Kırmızı token dışı.** `benim` token'larında kırmızı yok; sahip %0 için kırmızı istedi. `#FF9898` 7:1'i geçen en doygun kırmızıya yakın; tam kırmızı `#FF0000` görev çubuğunda 3,6 olurdu. Önce/sonra: [simge-100-v040.png](2026-09-27/simge-100-v040.png) → [simge-100-sonra.png](2026-09-27/simge-100-sonra.png).
- **Açık görev çubuğu.** Uygulama yalnız koyu temayı hedefliyor; ölçüm makinedeki koyu görev çubuğuna karşı.
- **Radius çelişkisi.** Makine yapılandırmasının notu 6 / pencere 12 diyor; `benim` token'ları 3 / 3. Token'lar izlendi.
- **Satır kademesi (stagger).** Panel sabit bir form, liste değil.
- **Menü animasyonu ve menü odağı.** Yerel `ContextMenuStrip`; açılışı sistem yapar, klavye seçimi üzerinde çizimiyle aynıdır (15,60).
- **Balon uyarısı.** Windows sistem arayüzü.
- **Etiket harf aralığı (tracking 0,08 em).** GDI+ `DrawString` harf aralığı ayarı sunmuyor.
- **Satır yüksekliği 1,6.** GDI+ çok satırlı metinde satır aralığını yazı tipinden alır; ipucu iki satırı geçmiyor.
- **Gölge değerleri (siyah %80, bulanıklık 40).** `CS_DROPSHADOW` sistem gölgesidir; değer verilemez.
- **Yazıyla arama (typeahead), web INP/CLS.** Web ölçütleri; masaüstü panelde karşılığı yok.
